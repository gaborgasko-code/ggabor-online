# ggabor.online

The bare domain https://ggabor.online, served by GitHub Pages from this repository.

| Path | Content |
|---|---|
| `/` | Forwards to `/landfall/` |
| `/landfall/` | Landing page of the game Landfall (hand-written, self-contained) |
| `/landfall/play/` | The game itself: a Godot web export |
| `/landfall/licences.txt` | Godot Engine (MIT) and Fraunces (OFL) licences |

Subdomains (`cv`, `planificador`, `cuidapp`, `pattogatott-kukorica`) live in their own repositories.

To update the game, replace the files in `landfall/play/` with a new web export and push.
